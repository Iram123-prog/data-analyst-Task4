# Sales & Financial Performance Dashboard

## Elevate Labs – Task 4

### Project Objective

The objective of this project is to design an interactive business dashboard using Microsoft Power BI. The dashboard helps stakeholders understand sales and financial performance and supports data-driven decision-making.

### Dataset

The project uses the Superstore Sales Dataset containing retail sales transaction data.

Important fields include:
- Order Date
- Sales
- Profit
- Quantity
- Category
- Sub-Category
- Region
- Segment
- Discount
- Customer information

### Tools Used

- Microsoft Power BI
- Canva
- GitHub

### Dashboard KPIs

The dashboard contains the following key performance indicators:

- **Total Sales:** 203.55K
- **Total Profit:** 88.34K
- **Total Quantity:** 5K
- **Profit Margin:** 43.4%

### Dashboard Visualizations

The dashboard includes:

1. Sales Trend Over Time
2. Sales by Category
3. Profit by Region
4. Sales by Sub-Category

### Interactive Features

The dashboard includes slicers for:

- Year
- Region
- Category
- Segment

These slicers allow users to filter the dashboard and interactively explore the data.

### Key Learning Outcomes

Through this project, I learned how to:

- Import and analyze data in Power BI
- Create KPI cards
- Create charts for business analysis
- Perform time-series analysis
- Use slicers and filters
- Design an interactive business dashboard
- Present data-driven insights

### Project Files

- `superstore.csv` – Dataset

## Conclusion

The interactive Power BI dashboard provides a clear overview of sales and financial performance. It combines KPIs, charts, and interactive filters to help stakeholders explore the data and make informed business decisions.
